# HR Rotations UI & Code Guidelines

هذه التعليمات خاصة بمشروع إدارة الموارد البشرية (HR Rotations). بمجرد استدعاء هذه المهارة، يجب عليك الالتزام بالقواعد التالية عند كتابة الأكواد:

## 1. Design System (نظام التصميم)
النظام يعتمد على تصميم **Glassmorphism** (الزجاجي الداكن). يجب استخدام المتغيرات التالية دائماً بدلاً من الألوان الثابتة:
- `var(--glass-bg)` : للخلفيات الشفافة.
- `var(--glass-border)` : للحدود.
- `backdrop-filter: blur(16px)` : لتأثير الزجاج.
- `var(--glass-shadow)` : للظلال.

## 2. Color Palette (لوحة الألوان)
يجب استخدام متغيرات الألوان المعرفة مسبقاً لتوحيد الهوية البصرية:
- `--primary`: #FF7B00 (برتقالي)
- `--secondary`: #00B4D8 (أزرق سماوي)
- `--success`: #10b981 (أخضر لحالة العمل Work)
- `--warning`: #f59e0b (برتقالي فاتح لحالة الراحة Rest)
- `--danger`: #ef4444 (أحمر للحذف والأخطاء)

## 3. UI Components (العناصر المرئية)
- **الأزرار:** استخدم كلاس `.btn` للأزرار الأساسية، وكلاس `.btn-outline` للأزرار الثانوية.
- **النوافذ المنبثقة (Modals):** يجب أن تتبع نفس هيكلة `.modal` و `.modal-content` الموجودة مسبقاً، مع تأثيرات الانبثاق (FadeIn).
- **الجداول:** يجب أن تحتوي دائمًا على تأثير الـ Hover على الصفوف لتحسين تجربة المستخدم.

## 4. Logic Rules (قواعد المنطق البرمجي)
- لا تسمح أبداً بوجود فترتي "عمل" أو "إجازة" متتاليتين؛ قم بدمجهما دائماً.
- يجب التأكد من عدم مسح أي بيانات سابقة من مصفوفة `records` عند التعديل، بل الاعتماد على التحديث فقط.

---
**الهدف:** الحفاظ على كود نظيف، هوية بصرية مبهرة وموحدة، وتسهيل عملية التطوير المستقبلية دون كسر التصميم الحالي.
