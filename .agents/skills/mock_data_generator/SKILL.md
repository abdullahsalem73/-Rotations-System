# Mock Data Generation Guidelines

عندما يُطلب منك توليد بيانات لاختبار النظام، التزم بما يلي:
1. **الواقعية**: استخدم أسماء عربية حقيقية (مثال: أحمد عبد الله، سارة محمد) وأسماء شركات واقعية.
2. **التنوع**: قم بتوليد بيانات تغطي حالات متعددة (موظف ليس لديه إجازات، موظف لديه تداخل في التواريخ، موظف جديد...).
3. **الصيغ الصحيحة**: توليد التواريخ بصيغة `YYYY-MM-DD` وأرقام الهواتف بصيغة حقيقية منطقية.
4. **الكمية**: إنتاج عدد كافٍ من السجلات (مثلاً 10-20 موظفاً) لضمان تجربة واجهة المستخدم بشكل صحيح واختبار الأداء.
