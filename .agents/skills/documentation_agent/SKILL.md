# Documentation Guidelines

1. **التعليقات البرمجية**: إضافة تعليقات قصيرة ومفيدة فوق الدوال (Functions) المعقدة لشرح "لماذا" كُتب هذا الكود وليس فقط "ماذا يفعل".
2. **تحديث الـ README**: في حال إضافة ميزة كبيرة للنظام، قم باقتراح تحديث لملف `README.md` يشرح الميزة الجديدة وكيفية استخدامها.
3. **JSDoc**: استخدام أسلوب `JSDoc` في كتابة تعليقات الدوال في الـ JavaScript لتوضيح أنواع المدخلات والمخرجات (`@param`, `@returns`).
4. **اللغة**: كتابة التعليقات بلغة إنجليزية تقنية واضحة، أو عربية فصحى مبسطة بناءً على سياق المشروع.
